## ✨ What Each File Does

**memory.py** - Manages SQLite database for persistent state  
**sandbox.py** - Executes code safely with protection mechanisms  
**lm_bridge.py** - Connects to LM Studio and manages AI interactions  
**launch_runtime.py** - Main entry point with interactive CLI  
**examples.py** - Shows how to use the system programmatically  
**test_installation.py** - Verifies everything is installed correctly
